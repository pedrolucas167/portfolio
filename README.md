# Portfolio - Pedro Lucas

Portfólio profissional moderno e de alto impacto construído com **TypeScript**, **React**, **Tailwind CSS** e **Vite**.

## 🚀 Tecnologias

- **Vite** - Build tool de próxima geração
- **React** - UI library progressiva
- **TypeScript** - Type-safety em larga escala
- **Tailwind CSS** - Design system utility-first
- **Framer Motion** - Animações fluidas e performáticas

## 📁 Estrutura do Projeto

```
portfolio/
├── src/
│   ├── components/        # Componentes TypeScript modulares
│   │   ├── Header.ts

│   │   └── index.ts
│   ├── config/

│   ├── styles/
│   │   └── main.css       # Estilos Tailwind + customizações
│   ├── types/

│   ├── utils/
```

## 🛠️ Desenvolvimento

### Pré-requisitos

- Node.js 18+
- npm ou yarn

### Instalação

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## ✨ Funcionalidades

- ✅ **Dark/Light Mode** - Tema automático baseado na preferência do sistema
- ✅ **Responsive Design** - Mobile-first com Tailwind CSS
- ✅ **Animações Suaves** - Com respeito a `prefers-reduced-motion`
- ✅ **Acessibilidade** - Skip links, ARIA labels, semântica HTML5
- ✅ **Performance** - Lazy loading, preconnect, otimizações de build
- ✅ **SEO** - Meta tags, Open Graph, Twitter Cards

## 📝 Scripts Disponíveis

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Inicia servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run preview` | Preview do build de produção |
